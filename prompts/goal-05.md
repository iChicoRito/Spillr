# Objective
## Deck Creation and Deck Lists

---

## Description
This objective focuses on implementing the Deck Creation and Deck Lists screen based on a provided Figma design. The goal is to accurately replicate the visual layout and interactive elements as designed, including a filterable deck list view and a drawer-based deck creation flow that allows users to define their deck's name, icon, and color.

---

## Objectives Breakdown

### 1. Main Objective Area
Implement the Deck Creation and Deck Lists screen by faithfully following the provided Figma image design in both layout and functionality.

---

### 2. Secondary Objective Area
Ensure that the interactive components — specifically the filter chips and the Create Deck drawer/sheet — behave as intended and are consistent with the Figma design.

---

### 3. Supporting Tasks

#### 3.1 Screen and Layout Implementation
- Build the Deck Creation and Deck Lists screen as a dedicated page
- Follow the actual design and layout from the Figma image accurately
- Ensure visual consistency with the provided design reference

#### 3.2 Filter Chips
- Implement filter chips on the Deck Creation screen
- Each chip corresponds to a deck category or type as shown in the design

#### 3.3 Create Deck Button and Drawer
- Implement the Create Deck button on the screen
- On button click, display a Drawer/Sheet component
- The drawer should allow the user to create their own deck

---

### 4. Detailed Breakdown

#### 4.1 Deck Lists Screen
Display the list of existing decks on the Deck Creation page, following the Figma layout accurately.

#### 4.2 Filter Chips
Render filter chips representing each deck type or category, enabling the user to filter the visible deck list.

#### 4.3 Create Deck Drawer/Sheet
Trigger a bottom drawer or sheet when the Create Deck button is tapped.

##### Drawer Contents
- **Deck Name** — Input field for the user to enter the name of their deck
- **Icons** — Selection of icons the user can assign to the deck
- **Color Selection** — Color picker or palette for the user to choose a deck color
- Follow the Figma design for the layout and arrangement of these elements within the sheet
