# Objective
## Minor Changes on UI/UX

---

## Description

This objective covers a set of minor UI/UX changes across three specific pages of the application: the **Play Page**, the **In-Game Page**, and the **On-Boarding Screens**. Each change is explicitly scoped to adjustments in layout, content, visual design, or text — strictly based on the provided input. No new features or assumptions are introduced.

---

## Objectives Breakdown

### 1. Main Objective Area
Apply targeted UI/UX modifications across three pages of the application as specified, ensuring visual consistency, layout correctness, and content accuracy.

---

### 2. Secondary Objective Area
Ensure that each change does not break existing layout integrity — particularly that removed elements are compensated by layout adjustments, and that revised screens strictly follow the provided Figma design reference without additions.

---

### 3. Supporting Tasks

#### 3.1 Play Page Tasks
- Remove the **"Pull Random Deck"** button from the Play Page
- Adjust the height of the cards to compensate for the removed button below
- Add a new card at the end with the following properties:
  - **Title:** Wildcard Tea
  - **Description:** Anything can show up. Answer bravely or pass suspiciously
  - **Color:** Neutral/700

---

#### 3.2 In-Game Page Tasks
- Change the timer duration to **2 minutes**
- Replace the word **"Spill"** with **"Answered"**
- Remove the **quotation marks (`" "`)** surrounding questions on the flipped card

---

#### 3.3 On-Boarding Screens Tasks
- Revise the design and layout of all **3 on-boarding screens** based strictly on the provided Figma reference
- Do **not** add any images or illustrations — placeholder space only; assets will be provided later

---

### 4. Detailed Breakdown

#### 4.1 Play Page — Button Removal & Card Height Adjustment
The **"Pull Random Deck"** button must be removed from the Play Page. Following its removal, the card components must have their height recalculated or adjusted to properly fill the space previously occupied by the button below.

#### 4.2 Play Page — New Card Addition
A new card is to be appended at the end of the card list. It must use:
- **Title:** Wildcard Tea
- **Description:** Anything can show up. Answer bravely or pass suspiciously
- **Background Color:** Neutral/700 (from the existing design token/color system)

#### 4.3 In-Game Page — Timer, Label & Card Text Fixes
Three distinct changes apply to the In-Game Page:

##### Nested Details
- The timer value must be updated to exactly **2 minutes (2:00)**
- The label **"Spill"** must be replaced with **"Answered"** wherever it appears on this page
- On the flipped card view, all question text must have its surrounding **double quotation marks removed** — the question content itself remains unchanged

#### 4.4 On-Boarding Screens — Layout Revision
All **3 on-boarding screens** must be redesigned to match the exact layout shown in the provided Figma reference designed by the requester.

##### Nested Details
- Follow the **exact layout** as shown in the Figma reference — no deviations
- Do **not** include any images or illustrations in the implementation at this stage
- Image/illustration assets will be supplied at a later time — reserve space only if the layout requires it per the reference
